# Science Concepts social promo

A 22 second, Chinese, 9:16 HyperFrames composition for RedNote and Instagram Reels. It uses real captures from the six experiment `index.html` pages and ends with the source repository and local-open instructions.

## Preview

From this directory, run:

```sh
npm run check
npx hyperframes preview --background
```

The project is silent and caption-led. It does not imply that the experiments are hosted at a public web URL; viewers download the repository and open an experiment's `index.html` in a browser.

Post-ready Chinese captions are in [PROMOTION.md](PROMOTION.md). Story research and the selected concept are in [STORYLINES.md](STORYLINES.md).
