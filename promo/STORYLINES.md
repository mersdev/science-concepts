# Storylines

## Selected: Let students test it

**Device and form:** A student's cursor changes one real experiment variable; the same cursor carries the lesson into five more experiments. Before and after captures show the source app's real apparatus, controls and live outputs, joined by quick object-match cuts.

**First two seconds:** The real Boyle piston and readout are visible on frame 0. Chinese text names both audiences: “老师课堂演示 · 学生自主探究”, followed by “亲手改变量 / 实时看结果”. A cursor reaches the piston; the pressure readout changes from 100 to 200 kPa as volume changes from 60 to 30 mL.

**Beats:** A classroom question → test Boyle's law → move through lens, circuit, melting, liquid pressure and free fall → show classroom and independent-study uses → GitHub download CTA.

**Look:** The app's warm light background, green ink and coral controls. Real interface captures remain recognizable, with large Chinese explanation above them. The close names all six experiments and points to the repository rather than implying a hosted website.

**Sound:** Silent, caption-led for muted social autoplay. No music or effects were retrieved.

## OpenCLI inspiration notes

Read-only OpenCLI search on RedNote surfaced several relevant patterns:

- “把复杂的知识点变成可交互模拟游戏可太棒了” used learning and visualization tags; the note showed 197 likes and 289 collects. That supports a useful, save-worthy framing around interactive practice.
- “一个人用 Claude 做了本 3D 物理课本” described real-time 3D experiments students can click and drag, plus a teacher-facing curriculum view. That supports showing a changed variable and its readout, then naming the classroom use.

Instagram Explore returned general trending Reels and carousels, which supports a vertical, caption-led video format but did not produce a relevant physics example. Instagram keyword user search returned HTTP 404 because this OpenCLI session is not logged in; no claim about physics-post performance is drawn from it.

## Alternative: A clearer classroom demo

**Device and form:** A teacher's pointer demonstrates one idea at a time, pulling back to the real workspace between close-ups. The cursor shows where to change a condition and the readout proves what changed.

**First two seconds:** A real free-fall ball begins moving; “需要更直观的演示？” lands above the apparatus.

**Beats:** Teaching question → six live demonstrations → show controls and outputs → teacher/student use → download CTA.

**Look:** Actual page captures, the existing palette and brief Chinese prompts.

**Sound:** A restrained music bed with real interaction clicks; no voiceover.

## Alternative: One cursor, six concepts

**Device and form:** One cursor becomes a visual guide, matching each real moving part to the next apparatus in a fast vertical sequence.

**First two seconds:** The Ohm's-law contact slides and current rises; “拖动，看见变化” appears.

**Beats:** First result → six object-to-object transitions → free-fall comparison → Chinese CTA.

**Look:** Tight, real captures of each instrument on the app's light ground; no invented interface.

**Sound:** Rhythmic music with sparse clicks and one payoff accent; no voiceover.
