# Review

## Creative call

Selected “Let students test it”: a learner changes one condition and sees the corresponding readout, while the first frame and closing card also state the teacher classroom-demo use. The six actual experiment pages appear in order. The alternate “teacher question” opener and the single-cursor concept were not built. The ending names all six topics and points to the GitHub repository; there is no configured live deployment URL.

## Checks and visual review

- HyperFrames check: 0 errors; runtime, layout, motion and contrast checks passed (9 layout samples; 29/29 text checks pass WCAG AA).
- Snapshot review covered scene starts and middle beats, all six cuts, a 360 px phone sheet, and a targeted pass on the opening, convex-lens values and closing card.
- The convex-lens line now describes the captured before/after values: object distance 60→40 cm and image distance 30→40 cm.
- Readouts in the captures match the experiment pages. Free fall keeps one live-output image because mass does not change those values.
- Sound was not heard or mixed. The film is intentionally silent for muted social autoplay; HyperFrames reports the corresponding `film_silent` warning.

## Weakest shot

The latent-heat model looks fairly still between the two captures; its clearest change is the melt-water readout from 0 to 50 g while temperature stays at 0°C. A future pass could use a short screen recording of the heating sequence if the interactive page supports a clean, repeatable recording.
