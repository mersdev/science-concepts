# Promo brief

## Intent

Promote the six interactive physics experiments to secondary-school teachers and students with a Chinese vertical video. The story blends a student's hands-on variable change with the teacher's classroom-demo use case.

## Confirmed

- Language: Chinese.
- Story: mix “Change one thing” and “A clearer classroom demo.”
- Source: the six real experiment pages in the parent repository.

## Assumptions

- Cross-post to RedNote and Instagram as a 9:16, 22-second, caption-led clip.
- Keep the source app UI in English and explain the demonstrations in Chinese overlays.
- Use the verified GitHub repository as the CTA. There is no configured public demo site, so the end card says to download and open an experiment page in a browser.
- Keep this preview silent because HeyGen is not signed in and no user-provided soundtrack is available. No paid media is planned.

## Review flow

Build the editable HyperFrames composition, check and preview it, then wait for approval before rendering the MP4.
