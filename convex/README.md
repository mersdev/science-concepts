# Convex lens

Use **Home** to return to the [experiment index](../index.html). The link appears only outside fullscreen.

Open `index.html`. Move the object from 10–80 cm, then slide the screen from 22–100 cm or use Find sharp image. Auto explore moves the object; Reset restores u = 60 cm and s = 30 cm.

Full Screen shows the bench, live distances and white-screen preview. The “Drag object” and “Drag screen” labels identify the movable components; drag either the label or the component. Focus a label and use arrow keys (Shift for larger steps), Home or End to move that component. The lens stays fixed. The preview shows sharp, out-of-focus or no sharp image states, and returns to the sidebar when fullscreen closes.

The ideal thin lens has fixed `f = 20 cm`, `1/f = 1/u + 1/v` and signed magnification `m = −v/u`. A real image is inverted; a virtual image is upright and cannot be focused on a screen. At u = f the image is at infinity. Blur is illustrative geometric defocus. Focus tolerance is ±0.35 cm; some real images lie beyond screen travel.

Edit `index.html`, `app.js` and `style.css` directly. Run `node check.mjs` from the repository root. See the root [README](../README.md) for common controls and file organization.
