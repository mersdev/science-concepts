# Ohm’s law

Open `index.html`. Drag the bench or adjust voltage from 0–12 V. Double voltage, use Auto sweep or Reset to 6 V. Switch between the fixed resistor and filament bulb; Compare overlays both curves. Full Screen shows only the interactive circuit and voltage/current output.

The resistor is 10 Ω at constant temperature. The qualitative steady-state bulb uses `V = 10I + 30I³`; it is not a calibrated physical bulb. At zero voltage, current is zero and V/I is undefined. Meters are ideal. The amber LED is a buffered teaching voltage indicator; its brightness does not change the test current.

Edit `index.html`, `app.js` and `style.css` directly. Run `node check.mjs` from the repository root. See the root [README](../README.md) for common controls and file organization.
