# 物理实验科学家 IP

给马来西亚中四、中五物理实验推广帖使用的原创科学家角色素材。角色走短圆可爱路线：大而简洁的眼睛、小鼻子、清楚的笑嘴和短手脚。外形以用户提供的卡通参考作为总体比例与表情清晰度参考，角色本身保持原创。

所有人物和道具 PNG 都是独立 RGBA 透明图层，不带画框、画布边框、白色贴纸描边或背景。颜色严格来自 [index.html](../secondary/index.html) 共用样式：`#fffefa`、`#f7f8f3`、`#293e3c`、`#71817b`、`#dfe5db`、`#397f73`、`#478d7a`、`#e58663`、`#f7f9f4`。

封面按参考海报的高层级排版处理：顶部小字，中上部大标题，下半部放大的科学家半身像。采用站内深绿底色与纸白、珊瑚色文字，不使用品牌标志或外框。可以直接打开 [cover-preview.html](characters/cover-preview.html) 预览排版。

标题是独立可编辑的透明 SVG：[cover-title.svg](characters/cover-title.svg)，文字为“拖一拖，物理就动起来”。半身角色也是独立透明 PNG：[cover-mascot-half.png](characters/cover-mascot-half.png)。[cover.svg](characters/cover.svg) 将两者与站内深绿底色分层组合；更换角色或标题时，它们仍可单独替换或缩放。
