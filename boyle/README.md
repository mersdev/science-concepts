# Boyle’s law

Open `index.html`. Drag the orange piston or adjust volume from 20–100 mL. Halve the volume, use Auto explore, or Reset to 60 mL. Full Screen shows only the interactive apparatus and its volume/pressure output.

The sealed sample has fixed temperature (300 K), fixed gas quantity and absolute pressure `P = 6000/V` kPa. The 24 illustrative particles retain their quantity and average speed. The pressure graph supports V and 1/V axes.

Edit `index.html`, `app.js` and `style.css` directly. Run `node check.mjs` from the repository root. See the root [README](../README.md) for common controls and file organization.
